# CareerSuit AI

> **Version:** 3.0

---

# Project Vision

CareerSuit AI is an AI-powered career development platform designed to help job seekers create stronger resumes, improve ATS compatibility, tailor resumes for specific job roles, and generate professional cover letters.

Unlike traditional resume analyzers, CareerSuit AI aims to provide multiple AI-powered career tools within a single platform, making the job application process smarter, faster, and more effective.

---

# Problem Statement

Many job seekers struggle with:

- Low ATS compatibility
- Weak resume content
- Generic cover letters
- Lack of personalized career guidance

Most existing tools solve only one of these problems. CareerSuit AI brings them together into a single platform.

---

# Objectives

- Analyze resumes using AI
- Calculate Resume & ATS Scores
- Rewrite resume bullet points
- Tailor resumes for job descriptions

# Architecture Overview

CareerSuit AI follows a modular architecture:

**React** → User Interface

**Spring Boot** → Authentication, Business Logic & Database

**FastAPI** → AI Services

**Gemini API** → AI Processing

**PostgreSQL** → Data Storage
